How the historical reconstruction works

The first snapshot is a community scrape from 3 June 2011. The missing early stages are approximated from release notes and the January 2014 source. Later snapshots use archived source and released vocabulary, including their historical relationships. Each quarter has a downloadable D3 tree. Read the reconstruction notes and sources.

These are vocabulary capabilities, not guarantees that a search engine understood them. Generic prose descriptions were always possible. The examples are invented, encoding-neutral illustrations. In the graph, node size reflects observed properties and green halos mark new types or properties.
