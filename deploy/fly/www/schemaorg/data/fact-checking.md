# Fact-checking: ClaimReview, Claim and MediaReview

## 2016-05-04 — ClaimReview enters Pending

Category: Non-Google
Status: Released in Pending (v3.0)
Summary: **The fact-checking community**, including Duke Reporters' Lab and Full Fact, helps develop structured fact-check reviews.

The v3.0 record dates the draft introduction; the later v3.2 announcement explicitly names the collaborating organizations. This does not assign every draft term to a particular participant.

## 2020-03-17 — MediaReview draft

Category: Project
Status: Released in Pending (v7.0)
Summary: `MediaReview` begins modelling media authenticity and misleading context alongside textual fact checks.

The release calls this editorial work in progress, not a complete design. It should not be portrayed as a finalized standard at this point.

Sources:

- [Proposal #2450](https://github.com/schemaorg/schemaorg/issues/2450)
- [Release record](https://schema.org/docs/releases.html#v7.0)
