# Datasets, DCAT and scientific metadata

## 2012-07-11 — Dataset vocabulary proposed

Category: Non-Google
Status: Proposal
Summary: **W3C Web Schemas participants** propose dataset descriptions drawing on DCAT, ADMS and VoID.

The July blog invites review; the terms were subsequently released in April 2013. The W3C wiki records the proposal and mappings.

Sources:

- [Proposal announcement](https://blog.schema.org/2012/07/11/describing-datasets-with-schema-org/)
- [W3C proposal and mappings](https://www.w3.org/wiki/WebSchemas/Datasets)

## 2016-08-09 — Scientific dataset descriptions broadened

Category: Project
Status: Released (v3.1; includes draft terms)
Summary: Dataset work adds funding, spatial and temporal coverage improvements, niche file formats and a draft measured-variables property.

The plural draft `variablesMeasured` was subsequently replaced by `variableMeasured`. The reviewed release record does not establish all individual affiliations.

Sources:

- [Proposal #1083](https://github.com/schemaorg/schemaorg/issues/1083)
- [Release record](https://schema.org/docs/releases.html#v3.1)

## 2023-05-16 — Science-on-Schema examples incorporated

Category: Non-Google
Status: Released examples (v16.0)
Summary: **ESIP's Science-on-Schema community** contributes scientific dataset and research-project examples, integrated by Richard Wallis.

The source branch includes commits by Melinda Minch; PR #3065 was merged on April 6, 2023, before the May release. Credit is for documentation and examples, not creation of the pre-existing Dataset type.
