# GS1 product vocabulary and interoperability

## 2016-02-22 — First large external extension

Category: Non-Google
Status: External extension
Summary: **GS1 SmartSearch** publishes an independent Web vocabulary extending Schema.org's product descriptions.

The announcement distinguishes GS1's independently managed extension from Schema.org's own hosted extensions. It describes collaboration via W3C and GitHub and a shared JSON-LD foundation.

Sources:

- [GS1 extension announcement](https://blog.schema.org/2016/02/22/gs1-web-vocabulary-welcoming-the-first-schema-org-external-extension/)

## 2021-07-07 — Product origin interoperability

Category: Alignment
Status: Released (v13.0)
Summary: **GS1 compatibility** motivates `countryOfAssembly` and `countryOfLastProcessing` for product descriptions.

Sources:

- [Proposal #991](https://github.com/schemaorg/schemaorg/issues/991)
- [Release record](https://schema.org/docs/releases.html#v13.0)

## 2024-01-22 — Certifications

Category: Alignment
Status: Released (v25.0)
Summary: `Certification` describes certifications of products, places, organizations and people, with **GS1 CertificationDetails compatibility**.

The release states compatibility; it does not establish direct organizational authorship by GS1.

Sources:

- [Proposal #3230](https://github.com/schemaorg/schemaorg/issues/3230)
- [Release record](https://schema.org/docs/releases.html#v25.0)

## 2024-05-20 — GS1 Digital Link

Category: Alignment
Status: Released (v27.0)
Summary: **GS1 Digital Link** gains a dedicated `hasGS1DigitalLink` property following a proposal by Matthias Wiesmann.

The issue describes product identifiers encoded as Web links, including identifiers for variants and lots. Author affiliation is not classified here.

Sources:

- [Proposal #3475](https://github.com/schemaorg/schemaorg/issues/3475)
- [Release record](https://schema.org/docs/releases.html#v27.0)
