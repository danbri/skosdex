## backstory

Property · current · [Schema.org](https://schema.org/backstory)

For an [[Article]], typically a [[NewsArticle]], the backstory property provides a textual summary giving a brief explanation of why and how an article was created. In a journalistic setting this could include information about reporting process, methods, interviews, data sources, etc.

Date evidence: First observed source declaration; it may precede release and does not establish invention.

Earliest available release snapshot: [3.4, 2018-06-15](https://github.com/schemaorg/schemaorg/blob/10be955038f15bf0df3d378db00ae3038691cfb3/data/releases/3.4/all-layers.nt). This is an upper bound on introduction.

## noBylinesPolicy

Property · current · [Schema.org](https://schema.org/noBylinesPolicy)

For a [[NewsMediaOrganization]] or other news-related [[Organization]], a statement explaining when authors of articles are not named in bylines.

Date evidence: First observed source declaration; it may precede release and does not establish invention.

Earliest available release snapshot: [3.4, 2018-06-15](https://github.com/schemaorg/schemaorg/blob/10be955038f15bf0df3d378db00ae3038691cfb3/data/releases/3.4/all-layers.nt). This is an upper bound on introduction.
