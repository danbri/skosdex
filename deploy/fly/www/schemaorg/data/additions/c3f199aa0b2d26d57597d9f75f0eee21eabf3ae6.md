## publicAccess

Property · current · [Schema.org](https://schema.org/publicAccess)

A flag to signal that the [[Place]] is open to public visitors.  If this property is omitted there is no assumed default boolean value.

## touristType

Property · current · [Schema.org](https://schema.org/touristType)
