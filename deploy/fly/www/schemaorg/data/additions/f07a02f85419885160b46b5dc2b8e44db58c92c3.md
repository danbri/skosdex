## phoneticText

Property · current · [Schema.org](https://schema.org/phoneticText)

Representation of a text [[textValue]] using the specified [[speechToTextMarkup]]. For example the city name of Houston in IPA: /ˈhjuːstən/.

Date evidence: First observed source declaration; it may precede release and does not establish invention.

Earliest available release snapshot: [6.0, 2020-01-21](https://github.com/schemaorg/schemaorg/blob/10be955038f15bf0df3d378db00ae3038691cfb3/data/releases/6.0/all-layers.nt). This is an upper bound on introduction.
