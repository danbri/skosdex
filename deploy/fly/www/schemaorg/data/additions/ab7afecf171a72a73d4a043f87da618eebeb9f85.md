## diversityStaffingReport

Property · current · [Schema.org](https://schema.org/diversityStaffingReport)

For an [[Organization]] (often but not necessarily a [[NewsMediaOrganization]]), a report on staffing diversity issues. In a news context this might be for example ASNE or RTDNA (US) reports, or self-reported.

Date evidence: First observed source declaration; it may precede release and does not establish invention.

## ownershipFundingInfo

Property · current · [Schema.org](https://schema.org/ownershipFundingInfo)

For an [[Organization]] (often but not necessarily a [[NewsMediaOrganization]]), a description of organizational ownership structure; funding and grants. In a news/media setting, this is with particular reference to editorial independence.   Note that the [[funder]] is also available and can be used to make basic funder information machine-readable.

Date evidence: First observed source declaration; it may precede release and does not establish invention.

Earliest available release snapshot: [3.4, 2018-06-15](https://github.com/schemaorg/schemaorg/blob/10be955038f15bf0df3d378db00ae3038691cfb3/data/releases/3.4/all-layers.nt). This is an upper bound on introduction.
