## amenityFeature

Property · current · [Schema.org](https://schema.org/amenityFeature)

An amenity feature (e.g. a characteristic or service) of the Accommodation. This generic property does not make a statement about whether the feature is included in an offer for the main accommodation or available at extra costs.

Date evidence: First observed source declaration; it may precede release and does not establish invention.

Earliest available release snapshot: [3.1, 2016-08-09](https://github.com/schemaorg/schemaorg/blob/10be955038f15bf0df3d378db00ae3038691cfb3/data/releases/3.1/all-layers.nt). This is an upper bound on introduction.

## LocationFeatureSpecification

Type · current · [Schema.org](https://schema.org/LocationFeatureSpecification)

Specifies a location feature by providing a structured value representing a feature of an accommodation as a property-value pair of varying degrees of formality.
