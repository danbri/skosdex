Category: Non-Google
Status: Released infrastructure (v11.0)
Summary: **Richard Wallis / Dataliberate** contributes the foundation for a Python 3 site build and clearer separation of vocabulary and presentation.

## 2023-05-16 — Contributor acknowledgements become separate Markdown

Category: Non-Google
Status: Released infrastructure (v16.0)
Summary: **Richard Wallis** separates acknowledgement text into Markdown files, linking them from term definitions using `contributor`.

PR #3202 was merged in November 2022 and listed in the May 2023 release. These files are a major evidence source for this timeline: commit authorship alone does not capture vocabulary provenance.

Sources:

- [Contribution commit](https://github.com/schemaorg/schemaorg/commit/6e08e18f)
