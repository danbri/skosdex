# Web standards, encodings and vocabulary mappings

## 2011-11-11 — RDFa Lite collaboration

Category: Non-Google
Status: Standards announcement
Summary: **W3C's RDFa community** works with Schema.org on using RDFa 1.1 Lite to publish the shared vocabulary.

This is advance notice of the RDFa work, not a claim that RDFa Lite was already a final Recommendation.

Sources:

- [RDFa Lite announcement](https://blog.schema.org/2011/11/11/using-rdfa-1-1-lite-with-schema-org/)

## 2012-06-07 — RDFa use endorsed

Category: Non-Google
Status: Standards announcement
Summary: **W3C RDFa work** enables Schema.org use alongside Microdata, reinforcing that the vocabulary is independent of its encoding.

Sources:

- [RDFa and Microdata update](https://blog.schema.org/2012/06/07/semtech-rdfa-microdata-and-more/)

## 2012-07-18 — External types become easier to combine

Category: Alignment
Status: Released (v0.96)
Summary: `additionalType` lets publishers combine Schema.org with more specific types from **external vocabularies** in Microdata.

Sources:

- [W3C proposal](https://www.w3.org/wiki/WebSchemas/additionalTypeProposal)

## 2025-12-08 — Cross-vocabulary equivalences

Category: Alignment
Status: Released (v29.4)
Summary: Mappings connect Schema.org to **UN/CEFACT, GS1 and OMG/FIBO-related vocabularies**; git credits include Matthias Wiesmann.

Mappings demonstrate reuse and interoperability. They do not establish that each standards organization directly participated in the PRs; the author's affiliation is not classified here.

Sources:

- [Class-equivalence commit](https://github.com/schemaorg/schemaorg/commit/73736057)

## 2026-03-19 — More equivalence annotations and exports

## 2026-06-17 — RDF collections and ordering clarified

Category: Project
Status: Documentation milestone
Summary: Schema.org documents explicit support for RDF collections and containers as property values, including JSON-LD `@list`.

The June 16 documentation commit is by Ryan Levering; the blog announcement is dated June 17. This is a data-model documentation change after v30.0, not a new numbered vocabulary release.

Sources:

- [Announcement](https://blog.schema.org/2026/06/17/supporting-ordering-in-schema-org/)
- [Documentation commit](https://github.com/schemaorg/schemaorg/commit/f5b95894)
