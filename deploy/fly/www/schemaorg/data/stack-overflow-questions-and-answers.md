# Stack Overflow model and question/answer vocabulary

## 2014-05-04 — Question and answer vocabulary

Category: Alignment
Status: Released (v1.1; date caveat)
Summary: **The Stack Overflow API model** informs `Question`, `Answer` and `QAPage` descriptions.

The persistent acknowledgement states that these types were based on the Stack Overflow API. This establishes design lineage, not direct participation by Stack Exchange staff. The release index gives v1.1 as 2014-05-04, despite placing it before v1.2 dated April 16. The timeline follows the printed date; both dates fall in Q2.
