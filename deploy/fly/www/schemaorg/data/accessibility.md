# Accessibility metadata and digital publishing

## 2013-12-04 — Accessibility properties added

Category: Non-Google
Status: Released (v1.0e)
Summary: **IMS Global's Access for All, the Accessibility Metadata Project and Yandex** contribute to accessible-content descriptions.

The December 5 announcement, signed by TV Raman (Google) and Chaals (Yandex), credits both projects. The release index dates the vocabulary addition to December 4.

Sources:

- [Announcement and collaboration credits](https://blog.schema.org/2013/12/05/content-accessibility/)
- [Release record](https://schema.org/docs/releases.html#v1.0e)

## 2017-03-23 — EPUB accessibility properties reach core

Category: Non-Google
Status: Promoted to core (v3.2)
Summary: **IDPF's EPUB accessibility community** contributes access modes, sufficient access modes and accessibility summaries.

These properties first appeared in the v3.0 Pending work. The v3.2 announcement explicitly credits the EPUB Accessibility Working Group and records their graduation to core.

Sources:

- [Announcement and credits](https://blog.schema.org/2017/03/23/schema-org-3-2-courses-fact-checking-digital-publishing-accessibility-menus-and-more/)
- [Accessibility proposal #1100](https://github.com/schemaorg/schemaorg/issues/1100)
